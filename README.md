# わりざんの ひっ算

小学4年生向けの、割り算の筆算を練習する PWA です。答えだけを入力するのではなく、
**たてる → かける → ひく → おろす** の順にマスを1つずつ埋めていきます。

- ビルド不要のバニラ JS（HTML / CSS / ES Modules）。外部ライブラリなし。
- オフラインで動作。ホーム画面に追加してアプリのように使えます。
- 記録は端末の localStorage だけに保存します。サーバーには何も送りません。

---

## ⚠️ iPhone / iPad では「ホーム画面に追加」して使ってください

iOS の Safari は、**タブで開いたまま**使っていると、しばらく使わなかったときに
保存データ（せいかいりつなどの記録）を消してしまうことがあります。

ホーム画面に追加して、そのアイコンから起動すれば記録は残ります。

**追加のしかた**
1. Safari でアプリを開く
2. 下の「共有」ボタン（□に↑）をタップ
3. 「ホーム画面に追加」をタップ

## 遊びかた

1. レベルをえらぶ（1回10問）
2. 光っているマスに、アプリ内のキーパッドで数字を1つずつ入れる
   （**2けた以上のマスは1の位から**光ります。くりあがり・くりさがりがあるので、筆算と同じ順です）
3. まちがえると、そのマスが赤くなって理由が出る。同じマスで2回まちがえると答えを見せて次へ進む
4. こまったら「ヒント」ボタン。いま入れるマスの考えかたが出る
5. 10問おわると、正答率と「まちがえやすいステップ」が出る

### レベル

| レベル | 内容 | 例 |
|---|---|---|
| 1 | わりきれる わりざん（2〜3けた ÷ 1けた） | 612 ÷ 6 |
| 2 | あまりの ある わりざん（2〜3けた ÷ 1けた） | 613 ÷ 6 |
| 3 | 2けたで わる わりざん（3けた ÷ 2けた） | 342 ÷ 27 |

1回10問には、つまずきやすい問題が必ず混ざります。

- 商の途中に 0 が立つ（例: 612 ÷ 6 = 102）
- わられる数の先頭のけたが、わる数より小さい（例: 124 ÷ 3）
- あまりが 0 になる（レベル2・3 でも1問）
- レベル3 では、十の位だけで見積もると**商が大きすぎてひけない**問題を2問以上

### レベル3の「商が大きすぎた」とき

27 を 20 と見て「34 の中に 2つ」と見積もると、27 × 2 = 54 になって 34 から引けません。
このアプリは、そこで赤くして止めるのではなく、**いったん 54 を書かせてから**
「34 から 54 は ひけないね」と伝えて、商を1小さくして入力し直す流れにしています。

## ローカルで動かす

ES Modules を使っているため `index.html` をダブルクリックして開く（`file://`）と動きません。
かならず localhost 経由で開いてください。

```bash
# どれか1つ。プロジェクトのルートで実行する
python -m http.server 8080
npx serve -l 8080
php -S localhost:8080
```

ブラウザで <http://localhost:8080/> を開きます。

> Service Worker は `localhost` か HTTPS でしか登録されません。
> 開発中にファイルを変えたのに反映されないときは、DevTools の
> Application → Service Workers で「Update on reload」を有効にするか、
> `sw.js` の `CACHE_NAME` のばんごうを上げてください。

スマートフォンの実機で試すときは、同じ Wi-Fi につないで
`python -m http.server 8080 --bind 0.0.0.0` を起動し、PC の IP アドレスでアクセスします
（ただし Service Worker は HTTP の LAN アクセスでは登録されません。
オフライン動作まで確認したい場合は HTTPS か localhost が必要です）。

## テスト

```bash
node --test
```

Node 標準のテストランナーだけを使います（Node 18 以降）。

受け入れ基準をそのままテストにしています。

| 確認していること | ファイル |
|---|---|
| 各レベル1000問が「商 × わる数 + あまり = わられる数」に一致する | `test/problem.test.js` |
| 生成した全問で、ステップ列を正解入力でたどると商とあまりが一致する | `test/steps.test.js` |
| 境界ケースが各レベルの毎回に混ざる | `test/problem.test.js` |
| 判定・2回まちがえたときの処理・商の修正フロー | `test/judge.test.js` |
| 記録の集計と、こわれたデータの扱い | `test/stats.test.js` |
| SW のキャッシュ一覧やアイコンの取りこぼし | `test/assets.test.js` |

## ファイル構成

```
index.html              画面（4つの section を切りかえる）
manifest.webmanifest    ホーム画面に追加するための設定
sw.js                   オフライン用の Service Worker
css/style.css           見ため（iPhone 12 mini をきほんに、たて・よこ両対応）
src/
  core/                 画面から切りはなした純粋関数（Node からテストできる）
    problem.js            問題生成・筆算のトレース・境界ケースの判定
    steps.js              ステップ列とマス配置の生成
    judge.js              1マスずつの判定・まちがいの記録・商の修正フロー
    stats.js              成績の集計
    rng.js                たねつきの乱数
  storage.js            localStorage の読み書き
  ui/                   描画だけを受けもつ
  app.js                画面遷移と進行
tools/make-icons.mjs    アイコン PNG の生成（Node の zlib のみ使用）
test/                   node --test で動くテスト
```

`src/core/` は DOM にも localStorage にも触りません。筆算のマスの位置も罫線も
`core/steps.js` が返すデータから決まるので、画面側は筆算のきまりを持っていません。

## 記録されるデータ

`localStorage` のキー `warizan.stats.v1` に、レベルごとの次の値だけを保存します。

- 入力したマスの数と、そのうち正解した数（＝正答率）
- 解いた問題数と、ノーミスで解けた問題数
- ステップ別（たてる / かける / ひく / おろす）のまちがい回数
- 最後に練習した日

きろく画面の「データを はじめから」で、いつでも全部消せます。
